Geek — многостраничный сайт (статический, без сборки)

Как опубликовать:
1. Загрузите всё содержимое этой папки на любой статический хостинг
   (GitHub Pages, Netlify, Cloudflare Pages, Vercel, обычный хостинг по FTP).
   Главная страница: index.html.
2. Структура должна остаться как есть: css/, js/, img/ рядом с html-файлами.
3. Для локального просмотра запустите в папке:  python3 -m http.server 8000
   и откройте http://localhost:8000

Страницы: index.html, catalog.html, about.html, register.html
Каталог и товары редактируются в js/data.js, иллюстрации товаров в js/art.js.
Шрифты (Google Fonts) и библиотеки (GSAP, Lenis, VanillaTilt, canvas-confetti) подгружаются
с CDN, поэтому для полной работы нужен интернет.

Магазин, товары, цены и люди вымышлены. Оплата не подключена, регистрация и корзина
работают только в браузере (localStorage).
